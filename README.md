# DampWatch

An original structural-dynamics laboratory for auditing where vibration energy goes.
Development in progress: generalized-alpha integration, exact state-space reference,
discrete energy balance, spectral amplification, and a reproducible numerical study.

Course grounding: structural dynamics and the time-integration topics identifiable
in the local CFD lab lecture filenames. No course text, exam, solution, private data,
or course source code is included. All examples will be synthetic and original.
